# SM Propietario

Panel instalable de consulta para propietarios que reciben información de **SM Ganadero**.

## Uso

1. Abra la aplicación publicada desde Safari en iPhone o Chrome en Android.
2. Instálela con **Añadir a pantalla de inicio** o **Instalar aplicación**.
3. En Android, comparta el documento `.smpair` desde WhatsApp con **SM Propietario** para preparar el teléfono.
4. Comparta cada archivo `.smprop` con **SM Propietario**; revise la vista previa y confirme la actualización.
5. La selección manual del archivo continúa disponible como alternativa y es el flujo utilizado en iPhone.

Los archivos de actualización están cifrados. Este repositorio contiene únicamente la interfaz pública; no contiene bases de datos, propiedades, claves ni información de clientes.
